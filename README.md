# 🌸 Jennys Nährstoffe

Minimalistisches, elegantes und wissenschaftlich fundiertes Single-Page-Wellness-Dashboard für Jennys tägliche Nahrungsergänzungsmittel und Mikronährstoff-Bedarfsdeckung.

![Jennys Nährstoffe Preview](assets/jenny_avatar.jpg)

---

## ✨ Features

- **🌸 Liebevolle Portrait-Integration**: Jennys Bild im Header mit Status-Glitzer und Tagesfortschritt.
- **🛍️ Professionelle E-Commerce Packshots**: Alle 9 Originalprodukte im High-End-Shop-Look (freigestellt auf Studio-Weiß).
- **🔘 Dualer Dosierungs-Modus**:
  - **Jennys Art (Individuell)**: 1 Kapsel/Einheit für alle Produkte – *außer Magnesium* (hier die vollen 3 Kapseln / 400 mg).
  - **Hersteller-Empfehlung (Standard)**: Offizielle Verzehrempfehlung laut Packungsbeilage.
- **🧬 30 Wissenschaftliche Nährstoff-Profile**:
  - Biochemische Hauptfunktionen & EFSA-Health Claims.
  - Bedeutung für Jennys Vitalität & Wohlbefinden.
  - Mögliche Anzeichen einer Unterversorgung (Mangel).
  - Bioverfügbarkeit & Einnahme-Tipps (Synergien, Fettlöslichkeit, Einnahmeabstände).
  - EFSA Tolerable Upper Intake Level (Sicherheitsbereich).
  - Verlinkung zu offiziellen Fachquellen (**DGE**, **EFSA**, **Examine.com**).
- **📊 2-Spalten Live-Dashboard**:
  - Linke Spalte (Sticky): Einnahmezeiten (Morgens, Mittags, Abends) mit täglicher Checkliste (`localStorage`).
  - Rechte Spalte: Echtzeit-Bedarfsdeckung mit D-A-CH / EFSA Referenzbalken, Suchfeld und Kategorie-Filtern (*Vitamine*, *Mineralstoffe*, *Spurenelemente*, *Fettsäuren & Vitalstoffe*, *Adaptogene & Pilze*).
- **⚡ 100% Statisch**: Reines HTML, CSS und Vanilla JS (ES Modules) – sofort einsatzbereit für **Cloudflare Pages**, GitHub Pages oder Vercel.
